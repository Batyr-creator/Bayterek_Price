# BayterekPrice — Оценка недвижимости в Астане (Full-Stack версия с Python и CSV)

Данный проект представляет собой полноценное приложение для оценки стоимости жилья в Астане, включающее фронтенд, бэкенд на Python и датасет (CSV).

📁 Структура проекта:
 `index.html` — Фронтенд (Bootstrap 5, карта Leaflet.js).
 `css/style.css` — Стили оформления.
 `js/app.js` — Клиентская логика.
 `backend/model.py` — Скрипт на Python с математической моделью и алгоритмом регрессии.
 `backend/apartments_astana.csv` — Датасет с реальными параметрами квартир и базовыми ценами.
`README.md` — Описание проекта.
